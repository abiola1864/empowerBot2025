RSVP tracking requires the rsvp_checkin feature to be enabled in a configuration. Users will receive a prompt before each forum with a one-tap RSVP, and a check-in message on the forum day. All responses are timestamped and linked to user profiles.
Issue Logging
ARTIFACT PREVIEW
Budget allocation Infrastructure Healthcare access Education funding
Issue logging lets users submit topics they want to raise at public forums via a simple WhatsApp prompt. Each submission is timestamped and linked to the user's profile. Requires the issue_logging feature to be enabled. Submissions will appear here with topic categorisation and export.
Submission Templates
ARTIFACT PREVIEW
Example guided template flow:
① What is the most important issue you want to raise?
② Which county department is responsible?
③ What specific action would you like the county to take?
Guided submission templates walk users through structured questions to help them formulate specific forum inputs. Responses are logged against the user's profile. Requires the submission_templates feature.

WhatsApp's native read receipt webhooks (status: sent → delivered → read) can be logged per message per user. This requires storing a message_log collection on each outbound message and listening to status update webhooks. When implemented, this table will show per-user delivery and read rates for all outbound content including forum alerts, budget briefs, and quiz questions.

Scheduled broadcast system (not yet built)
Admin creates a broadcast → selects target configuration → sets send time → platform delivers to all users in that config and tracks delivery status per user.
Forum alerts and budget briefs require a broadcast/scheduler feature. The admin would upload content, set a delivery time, and select which configuration(s) to target. Requires WhatsApp template message approval for outbound messages outside the 24-hour window.
