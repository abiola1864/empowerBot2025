How location codes work
When a new user first messages the bot, they are asked to enter a location code before they can continue. Codes are generated here and distributed to participants in each area (e.g. handed out at a community meeting or sent with an invitation). Users who don't have a code can type OPEN to continue with location marked as Unspecified. Each code is linked to a location and optionally to a configuration — so assigning a code automatically places the user in the correct research group.
